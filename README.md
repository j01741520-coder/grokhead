# Grok Bot · 3D

An interactive 3D take on the Grok Bot app icon, in a single web page. Everything is generated in code.

**Play:** https://j01741520-coder.github.io/grokhead/

- Move the mouse: the eyes follow the cursor
- Click or Space: squish and change expression
- 1–5: glossy / plush / glass / neon / voxel
- T: thinking · S: screenshot · R: record · G: export .glb
- Leave it alone and it falls asleep

Built with [three.js](https://threejs.org/) (MIT).
